# 학교 바탕화면 위젯

Windows 바탕화면에 **캘린더 · 수업시간표 · 오늘 학교행사** 위젯을 띄워주는 프로그램입니다.
macOS 바탕화면 위젯처럼 **둥근 모서리의 반투명 글래스 스타일**로 표시됩니다.
배경판만 비치고 글자는 100% 선명하게 보이도록 위젯마다 창 2개(배경판 + 내용)를 겹쳐 그립니다.
Python 기본 라이브러리(tkinter)만 사용하므로 추가 설치가 필요 없습니다.

## 위젯 구성

| 위젯 | 기능 |
|---|---|
| **캘린더** | 월간 달력, 오늘 날짜 강조, 일·공휴일(대체공휴일 포함) 빨간색 / 토요일 파란색, 일정이 있는 날 점 표시. 날짜에 마우스를 올리면 일정 미리보기, 클릭하면 일정 추가 |
| **수업시간표** | 오늘 시간표 + 현재 교시 강조, 지난 교시는 흐리게. "지금 3교시 수학 · 11:35까지 (12분 남음)", "쉬는 시간", "점심시간", "오늘 수업 끝!" 같은 상태 표시. `주간` 버튼으로 월~금 주간 시간표 보기 |
| **오늘 학교행사** | 오늘의 행사·공휴일, 30일 안에 다가오는 일정을 D-day 로 표시 |

## 실행 방법

### 방법 1) Python 으로 실행
1. [python.org](https://www.python.org/downloads/) 에서 Python 3.9 이상 설치 (설치 시 **Add python.exe to PATH** 체크)
2. 이 폴더의 `run.bat` 더블클릭

### 방법 2) exe 파일로 만들기
1. `build_exe.bat` 더블클릭 → `dist\SchoolWidget.exe` 생성
2. exe 를 원하는 폴더에 두고 실행 (Python 이 없는 PC 에서도 실행 가능)

## 사용법

- **이동**: 위젯 제목줄을 마우스로 끌어서 옮깁니다. (위치는 자동 저장)
- **메뉴**: 위젯 아무 곳이나 **마우스 오른쪽 클릭**
  - 시간표 편집 / 학교행사·일정 편집 / 설정 / 위젯 숨기기 / 위치 초기화 / 종료
- **시간표 편집**: 교시 이름·시작·종료 시간과 요일별 과목 입력. 교시 추가/삭제 가능
- **일정 추가**: 캘린더에서 날짜 클릭, 또는 학교행사 위젯의 `+` 버튼
- **설정**
  - 다크 / 라이트 테마
  - 배경 불투명도(15~100%) - 글자는 그대로, 배경판만 투명해집니다
  - 배경 흐림(블러) 효과 - 실험적 기능. 모서리가 각지게 보이는 등 PC 에 따라 어색하면 꺼주세요
  - 창 배치: *바탕화면에 고정(다른 창 뒤)* / 일반 / *항상 위*
  - 표시할 위젯 선택, 위치 잠금
  - **Windows 시작 시 자동 실행** (시작프로그램 폴더에 등록)

## 나이스(NEIS) 자동 연동 (선택)

[교육정보 개방포털](https://open.neis.go.kr)의 공개 API 로 **우리 반 시간표**와 **학사일정(학교행사)** 을 자동으로 불러올 수 있습니다.

1. open.neis.go.kr 회원가입 → 마이페이지 → **인증키 발급** (무료)
2. 위젯 오른쪽 클릭 → 설정 → **나이스(NEIS) 연동** 탭
3. 인증키 입력 → 학교 이름 검색 → 목록에서 우리 학교 선택 → 학년·반 입력
4. `시간표 지금 불러오기` / `학사일정 지금 불러오기` 클릭
5. "시작할 때 자동 불러오기"를 켜두면 하루 한 번 자동으로 갱신됩니다.

> 인증키 없이도 학교 검색은 되지만 결과가 5건으로 제한되어 시간표·학사일정은 일부만 불러옵니다.
> 시간표 자동 불러오기를 켜면 직접 편집한 시간표가 나이스 시간표로 덮어써집니다.

## 데이터 저장 위치

`%APPDATA%\SchoolWidget\data.json` (메뉴 → *데이터 폴더 열기*)
이 파일을 백업하면 시간표와 일정을 그대로 옮길 수 있습니다.

## 참고

- 라이트 테마는 어두운 배경화면에서 글자 가장자리가 밝게 번져 보일 수 있습니다. 이때는 다크 테마를 쓰거나 배경 불투명도를 높여주세요.

- 음력 공휴일(설날·추석·부처님오신날)은 2025~2027년만 내장되어 있습니다. 이후 연도나 학교 재량휴업일은 나이스 학사일정 연동으로 보완하세요.
- 중복 실행은 자동으로 막아집니다.
